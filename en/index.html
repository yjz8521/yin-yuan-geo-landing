How it works

Four-step loop

Matches the in-product flow: entity → packs → publish → monitor.

  1. 01

    Entity card

    Structure brand, category, claims, competitors, and scenarios.

  2. 02

    Engine packs

    Titles, outlines, and channel lists for each CN engine; global engines reuse the same entity facts.

  3. 03

    Publish

    Push to creator drafts and brand CMS along P0/P1 channels.

  4. 04

    Monitor mentions

    Run fixed prompts, track naming / citations / recommendations, then diagnose.
